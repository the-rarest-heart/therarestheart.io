How do I reset a domain user password in Active Directory without locking the account?
TheGERD
Domain Password Reset — AD

1. Open Active Directory Users & Computers
2. Right-click the user → Reset Password
3. Uncheck "User must change at next login" if you're resetting for them
4. Confirm — account stays unlocked automatically

⚠ Verify you have Domain Admin rights before proceeding.

SOP-06

01. Isolate the infected machine from the network — disable NIC or pull cable.
02. Boot into Safe Mode. Run offline AV scan using bootable USB (Malwarebytes / ESET).
03. Quarantine and remove flagged files. Document all findings for the incident report.
04. Reconnect to network. Run live scan. Confirm clean. Reset user credentials.
05. File incident report in GERD. Close ticket and notify supervisor.
